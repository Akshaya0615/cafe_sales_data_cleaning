# Cafe Sales Data Cleaning Project

## Overview

This project mailny focuses on cleaning and preparing a dirty cafe sales dataset for analysis using python/pandas.

## The dataset contains
- Missing values
- Invalid entries such as ERROR and UNKNOWN
- Dulpicates
- Inconsistent formatting

## Tools Used 
- Python
- Pandas
- Google Colab
- GitHub

 ## Data Cleaning Steps
 1. Loaded dataset using Pandas
 2. Identified missing and invalid values
 3. Replaced ERROR and UNKNOWN entries
 4. Removed dupicate rows
 5. Converted date columns into proper format
 6. Saved cleaned dataset

## Outcome
Successfully prepared a clean and analysis ready dataset.
